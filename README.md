## About

KARA Bridge는 방사선 과학기술 분야의 연구성과가 산업 현장으로 이어지도록 돕는 기술사업화 플랫폼입니다.
연구기관, 대학, 기업을 연결해 기술이전과 사업화, 산업 협력을 지원합니다.

## What we do

- 방사선 기술 정보 공유 및 기술 매칭
- 기술이전과 사업화 지원
- 연구기관, 대학, 기업 간 협력 네트워크 구축
- 방사선 산업 동향과 정보 제공
